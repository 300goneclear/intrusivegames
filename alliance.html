How it works: Register first if you're actually playing. Once the admin closes registration, 3 rounds begin — random pairs among registered players each round, blind Split or Steal. Both split = +1 each. One steals, one splits = stealer gets +2, splitter gets 0. Both steal = a number duel: guess closest to a hidden target (1–25), winner gets +2, loser gets 0. After 3 rounds, whoever has the fewest points does a public dare. If it's a tie, everyone tied goes into one more number duel — this time, whoever's farthest from the target is the one who actually does it. ⚠ Dares are meant to be funny, not humiliating. Skip anything that crosses a line for someone.
